## Demo photographs

Every photo is served from `https://images.unsplash.com/photo-<id>`. Images on that host are offered under the [Unsplash License](https://unsplash.com/license), which allows free commercial use and does not require attribution. Unsplash+ (paid) images are served from `plus.unsplash.com`, and none are used here. The Unsplash License **does not** allow compiling Unsplash photos into a similar or competing service. For that reason the photos are **not bundled** in the download and are presented only as replaceable demo content.

**Photographer credits: unverified.** Attempts to match each CDN image ID to its Unsplash photo page and photographer through web search were unsuccessful, because search engines do not index these CDN IDs. Rather than guess, the photographer column is left blank. **Seller action:**
1. Open each image URL below.
2. Find the photo on unsplash.com, for example with a reverse-image search or the Unsplash search box.
3. Record the photographer and the photo page URL here.
4. Confirm that the page shows the standard *Unsplash License*, not Unsplash+.
